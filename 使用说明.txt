论文管理工具 · 使用说明
============================

一、怎么启动
  1. 双击运行对应系统的程序（注意芯片要匹配）：
     Windows        paper-manager-windows-amd64.exe
     Mac(M系列)      paper-manager-darwin-arm64
     Mac(Intel)     paper-manager-darwin-amd64
     Linux          paper-manager-linux-amd64
     （查芯片：苹果菜单 → 关于本机；「Apple M…」选 arm64，「Intel」选 amd64）
  2. 启动后会自动打开浏览器（地址 http://localhost:8080）。
     没自动打开的话，手动在浏览器输入这个地址即可。

二、Mac 打不开（提示「已损坏」或「无法验证开发者」）
  这是 macOS 对未签名程序的正常拦截，二选一：

  方法1（macOS 15 及以上）：
    打开 系统设置 → 隐私与安全性，滚动到页面底部，
    会看到「paper-manager-…」被阻止的提示，点「仍要打开」。

  方法2（通用，推荐）：
    打开「终端」（启动台搜"终端"），输入
      xattr -cr
    注意 xattr -cr 后面有一个空格，然后把程序文件拖进终端窗口，
    回车。之后就能正常双击运行了。

  也可以不用下载，直接复制这一行到终端执行（自动下载并安装）：
    curl -fsSL https://github.com/UndertaK33r/paper-manager/releases/latest/download/install.sh | bash
    装好后运行：cd ~/paper-manager && ./paper-manager

三、数据存在哪里
  程序旁边自动生成 data 文件夹，论文记录、PDF、笔记都在里面。
  备份 = 把 data 文件夹整个拷走；换电脑 = 拷过去继续用。
  更省事的办法：页面右上角「管理」→「导出备份」，会下载一个压缩包
  （含数据库快照和全部 PDF）。恢复时退出程序，把包里的 data 文件夹
  解压覆盖到程序旁边，再启动即可。

四、笔记支持 Markdown
  详情页或全屏阅读的笔记框里可以直接写 Markdown，点「预览」看渲染效果，
  再点「编辑」回到输入。支持：# 标题、**加粗**、*斜体*、- 列表、1. 编号、
  > 引用、`代码`、表格、~~删除线~~、[链接](网址)。
  偏好会记住：上次选了预览，下次打开还是预览。

五、阅读模式与标注
  详情页的阅读区有两个视图，点按钮切换：
    · PDF 原文 —— 浏览器原生阅读器
    · 阅读模式 —— 把提取出的全文重排成好读的正文（自动合并换行、
      还原英文断词、识别小节标题、按页分隔）。进入全屏会自动切过去。
  在阅读模式里用鼠标选中一段文字，会弹出颜色按钮，点一下即完成高亮
  （黄/绿/蓝/粉）。点已高亮的地方可以改颜色、写备注、删除。
  标注会跟着论文保存，刷新后仍在；详情页「标注」一栏可以查看全部标注、
  点击定位到正文，也能一键按 Markdown 插入到笔记里。
  提示：如果阅读模式提示没有全文，点「重新提取全文」即可。

六、误删了怎么办
  删除论文会先进「回收站」，不会直接删掉文件。
  打开「管理」→「回收站」，可以逐篇恢复，也可以「彻底删除」或「清空回收站」
  （只有彻底删除/清空才会真正删掉 PDF 文件）。

七、怎么关闭 / 更新
  关闭黑色命令行窗口即为退出（数据自动保存）。
  更新版本：用新版程序文件替换旧的即可，数据不受影响。

八、常见问题
  1. 提示端口被占用：在命令行里用 PORT=9090（Windows 用
     set PORT=9090）再运行，然后访问 http://localhost:9090
  2. 提示 Bad CPU type / cannot execute binary：
     下载的芯片版本不对，换另一个（见「一、1」）。
  3. 想让局域网其他设备访问：默认即可，用本机 IP 访问
     （查 IP：Windows 运行 ipconfig，Mac 运行 ipconfig getifaddr en0）
  4. 想加密码：启动前设置 AUTH_USERNAME 和 AUTH_PASSWORD 两个环境变量，
     之后打开页面需要输入密码。
